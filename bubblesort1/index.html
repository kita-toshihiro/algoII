アルゴリズム擬似コード

function bubbleSort(array):
n = array.length
for i from 0 to n - 1:
for j from 0 to n - i - 2:
if array[j] > array[j + 1]:
swap(array[j], array[j + 1])
mark array[n - 1 - i] as sorted

バブルソートの仕組み

バブルソート（泡ソート）は、配列の隣り合う2つの要素を先頭から順に比較し、大きさが逆であれば入れ替えていく単純な並び替えアルゴリズムです。

アルゴリズムの特徴
  • 1周（Pass）完了するごとに、未確定の中での最大値が一番右端へ確定します。
  • 水中で軽い泡（大きな値）が上へ浮き上がっていく様子に似ているためこの名がついています。
  • 安定ソート（同じ値の順序が保たれる）であり、追加のメモリをほとんど必要としません。
